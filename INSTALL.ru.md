# DeepRrr: установка

English: [INSTALL.md](INSTALL.md).

DeepRrr - маленький переводчик для Mac в духе DeepL. Выделяете текст, дважды нажимаете Cmd+C, и рядом появляется перевод. Есть и окно с двумя панелями: оригинал и перевод. Переводит встроенный переводчик Apple, без аккаунтов и подписок.

> **Статус:** сборок, заверенных Apple, пока нет: регистрация разработчика в Apple ещё идёт. До этого выходят **предварительные сборки** (preview), подписанные сертификатом автора, но не проверенные Apple. Первая, `0.21.0` preview, опубликована для пробной установки у друзей: если что-то не получается, напишите автору. Как её ставить, описано в разделе [«Предварительная сборка»](#предварительная-сборка-без-заверения-apple) ниже. Остальные разделы (установщик `install-deepr.sh`) относятся к будущим заверенным сборкам.

## Предварительная сборка (без заверения Apple)

Пока у автора нет сертификата Apple Developer ID, DeepRrr выходит предварительными сборками на [странице релизов](https://github.com/vokhmin/deepr-releases/releases) с пометкой **Pre-release** и словом `preview` в названии. Такая сборка подписана личным сертификатом автора, но Apple её не проверяла, поэтому macOS при первом запуске её заблокирует, и разрешить запуск нужно вручную. Ставьте её, только если доверяете автору, и скачивайте только с этой страницы.

**Отпечаток сертификата.** Подпись проверяется по отпечатку сертификата автора: `d7b862527611395df9bb15be986dfd655f32ea09`. Автор пришлёт его вам отдельным сообщением; сверьте, что он совпадает с этим. Если не совпадает, ничего не ставьте.

Установщик `install-deepr.sh` предварительные сборки не ставит: всё делается вручную, по шагам ниже. Команды вводятся в **Терминале**. В примерах версия `0.21.0`, замените её на версию из имени скачанного файла.

1. Скачайте в «Загрузки» два файла одной предварительной сборки: `DeepRrr-0.21.0-preview.zip` и `DeepRrr-0.21.0-preview.zip.sha256`.
2. Проверьте контрольную сумму, должно появиться `OK`:

   ```sh
   cd ~/Downloads
   shasum -a 256 -c "DeepRrr-0.21.0-preview.zip.sha256"
   ```

3. Распакуйте во временную папку. Если папка `~/Downloads/deepr-new` осталась от прошлого раза, сначала удалите её, иначе команда остановится:

   ```sh
   mkdir ~/Downloads/deepr-new && ditto -x -k "DeepRrr-0.21.0-preview.zip" ~/Downloads/deepr-new
   ```

4. Проверьте и установите одним блоком: скопируйте его в Терминал целиком. Блок проверяет, что приложение подписано именно сертификатом автора, не изменено и это действительно DeepRrr; затем откладывает старую копию (если она есть) и ставит новую целиком. При любой ошибке он останавливается, ничего не меняя дальше, и пишет почему. Если DeepRrr запущен, сначала закройте его (значок в строке меню > Quit DeepRrr). Раньше программа называлась DeepR: если старая копия ещё лежит в `~/Applications/DeepR.app`, блок один раз остановится и попросит закрыть её и перенести в Корзину; настройки сохранятся. В конце должно появиться `УСТАНОВЛЕНО И ПОДПИСЬ ВЕРНА`:

   ```sh
   bash -eu <<'EOF'
   req='=identifier "dev.av.deepr" and certificate root = H"d7b862527611395df9bb15be986dfd655f32ea09"'
   new="$HOME/Downloads/deepr-new/DeepRrr.app"
   app="$HOME/Applications/DeepRrr.app"
   legacy="$HOME/Applications/DeepR.app"
   backup=""
   fail() { echo "$*" >&2; if [ -n "$backup" ]; then echo "Старая копия отложена: $backup" >&2; fi; exit 1; }
   /usr/bin/codesign --verify --deep --strict -R "$req" "$new" || fail "ПОДПИСЬ НЕ ВЕРНА: ничего не запускайте, удалите deepr-new и напишите автору"
   [ "$(/usr/bin/defaults read "$new/Contents/Info.plist" CFBundleIdentifier)" = dev.av.deepr ] || fail "Не тот идентификатор приложения: остановитесь и напишите автору"
   if [ -e "$legacy" ] || [ -L "$legacy" ]; then
     if [ ! -L "$legacy" ] && [ -d "$legacy" ] && [ "$(/usr/bin/defaults read "$legacy/Contents/Info.plist" CFBundleIdentifier 2>/dev/null)" = dev.av.deepr ]; then
       fail "Старая версия DeepR лежит в ~/Applications/DeepR.app. Один раз при переходе: закройте DeepR (значок в строке меню > Quit DeepR), перенесите ~/Applications/DeepR.app в Корзину и повторите"
     fi
     fail "По пути ~/Applications/DeepR.app лежит что-то неожиданное: разберитесь вручную, ничего не заменено"
   fi
   procs=$(/bin/ps -axo args=) || fail "Не удалось получить список процессов: ничего не заменено"
   case "$procs" in *"$legacy/Contents/MacOS/"*) fail "Старая версия DeepR ещё запущена: закройте её (значок в строке меню > Quit DeepR) и повторите" ;; esac
   case "$procs" in *"$app/Contents/MacOS/"*) fail "DeepRrr запущен: закройте его (значок в строке меню > Quit DeepRrr) и повторите" ;; esac
   mkdir -p "$HOME/Applications"
   [ ! -L "$app" ] || fail "~/Applications/DeepRrr.app - ссылка, а не приложение: разберитесь вручную"
   if [ -e "$app" ]; then
     [ -d "$app" ] && [ "$(/usr/bin/defaults read "$app/Contents/Info.plist" CFBundleIdentifier 2>/dev/null)" = dev.av.deepr ] || fail "~/Applications/DeepRrr.app - не DeepRrr: разберитесь вручную"
     candidate="$HOME/Downloads/DeepRrr-previous-$(date +%Y%m%d-%H%M%S).app"
     [ ! -e "$candidate" ] && [ ! -L "$candidate" ] || fail "Резервная копия с таким именем уже есть: подождите минуту и повторите"
     mv "$app" "$candidate" || fail "Не удалось отложить старую копию: ничего не заменено"
     backup="$candidate"
   fi
   [ ! -e "$app" ] && [ ! -L "$app" ] || fail "Старая копия не убрана: ничего не заменено"
   mv "$new" "$app" || fail "Не удалось поставить новую копию: верните старую (шаг 7)"
   /usr/bin/codesign --verify --deep --strict -R "$req" "$app" || fail "После установки подпись не сходится: верните старую копию (шаг 7)"
   echo "УСТАНОВЛЕНО И ПОДПИСЬ ВЕРНА"
   if [ -n "$backup" ]; then echo "Старая копия отложена: $backup"; fi
   EOF
   ```

   Если появилось сообщение об ошибке подписи или идентификатора, ничего не запускайте, удалите папку `deepr-new` и напишите автору. Не копируйте новую версию поверх старой в Finder.
5. Первый запуск: `open ~/Applications/DeepRrr.app`. macOS покажет, что не может проверить приложение, и не откроет его: нажмите **Готово**. Затем откройте **Системные настройки > Конфиденциальность и безопасность**, прокрутите до раздела **Безопасность**, нажмите **Всё равно открыть** рядом с сообщением о DeepRrr, введите пароль Mac и в следующем окне снова выберите **Всё равно открыть**. Если macOS пишет, что приложение **повреждено** или содержит **вредоносное ПО**, или кнопки «Всё равно открыть» нет, остановитесь: удалите DeepRrr и напишите автору. Не снимайте карантин командами из интернета.
6. Дальше как в разделе [«Первый запуск»](#первый-запуск): «Универсальный доступ», языки Apple.
7. Когда новая версия заработала, удалите отложенную копию (блок назвал её путь, `~/Downloads/DeepRrr-previous-...app`) и папку `~/Downloads/deepr-new`. Если новая версия не запускается: закройте её, перенесите `~/Applications/DeepRrr.app` в Корзину и верните отложенную копию: `mv ~/Downloads/DeepRrr-previous-<дата>.app ~/Applications/DeepRrr.app`.

**Обновление** предварительной сборки: те же шаги 1-7. Разрешение «Универсальный доступ» задумано сохраняться между сборками с одной подписью, но это ещё проверяется: после обновления убедитесь, что двойное Cmd+C работает, иначе включите DeepRrr в «Универсальном доступе» заново. macOS может снова попросить «Всё равно открыть».

**Переход на заверенные сборки.** Когда появятся сборки, заверенные Apple, их подпись будет другой. Разрешения тогда, скорее всего, придётся выдать заново; настройки и данные DeepRrr сохранятся.

## Что нужно

- Mac на **Apple Silicon** (M1 и новее). Mac на Intel не поддерживаются.
- **macOS 15** или новее.
- Четыре файла одной версии со [страницы релизов](https://github.com/vokhmin/deepr-releases/releases): `DeepRrr-<версия>.zip`, `DeepRrr-<версия>.zip.sha256`, `install-deepr.sh`, `install-deepr.sh.sha256`.

Xcode, Homebrew и прочие инструменты разработчика не нужны.

## Установка

1. Сохраните все четыре файла в одну папку, например в «Загрузки».
2. Откройте **Терминал** (Программы > Утилиты > Терминал) и проверьте сам установщик:

   ```sh
   cd ~/Downloads
   shasum -a 256 -c install-deepr.sh.sha256
   ```

   Должно появиться `install-deepr.sh: OK`. Если нет, ничего не запускайте и напишите мне.
3. Установите DeepRrr. Замените `0.21.0` на версию из имени скачанного файла (здесь это только пример):

   ```sh
   bash install-deepr.sh "DeepRrr-0.21.0.zip" --open
   ```

   Установщик сам проверит, что это настоящий DeepRrr, подписанный мной и проверенный Apple, поставит его в папку «Программы» вашего пользователя (`~/Applications`) и запустит. Если какая-то проверка не прошла, он ничего не установит и объяснит почему.
4. Если macOS спросит, открыть ли приложение, загруженное из интернета, нажмите **Открыть**.

## Первый запуск

1. DeepRrr живёт в строке меню вверху экрана и в Dock. Окно первого запуска проведёт по шагам.
2. **Универсальный доступ** (обязательно): Системные настройки > Конфиденциальность и безопасность > Универсальный доступ, включите **DeepRrr**. Без этого двойное Cmd+C не сможет прочитать выделенный текст.
3. **Запись экрана и системного звука** (по желанию): Системные настройки > Конфиденциальность и безопасность > Запись экрана и системного звука. Нужна только для перевода текста со скриншотов, можно пропустить.
4. **Языки перевода Apple**: в настройках DeepRrr откройте Services > Apple Translation > Language Packs, выберите пару (например English и Russian), нажмите **Check & Download** и дождитесь **Installed**. Без скачанной пары Apple не переводит.
5. **Gemini** (по желанию): второй переводчик, облачный. Нужен ваш собственный ключ из [Google AI Studio](https://aistudio.google.com/apikey), он вставляется в настройках DeepRrr; переводимый текст уходит в облако Google, возможны лимиты и плата по вашему ключу. В окне перевода выберите Gemini в поле Engine; во всплывающем окне по умолчанию работает Apple. Без ключа всё работает на Apple.

## Как пользоваться

- **Cmd+C+C** (дважды Cmd+C, не дольше 0,8 секунды между нажатиями): перевод выделенного текста во всплывающем окне.
- **Opt+D**: перевод выделенного, **Opt+V**: перевод того, что в буфере обмена.
- Если в каком-то приложении (например в Slack или в некоторых терминалах) не срабатывает Cmd+C+C или Opt+D, скопируйте текст обычным Cmd+C и нажмите Opt+V, или вставьте его в окно перевода.
- Значок DeepRrr в Dock: клик открывает окно перевода, правый клик показывает меню.
- По умолчанию русский текст переводится на английский, всё остальное на русский. Это меняется в настройках.

## Обновление

Когда выйдет новая версия, скачайте её файлы и запустите установщик ещё раз тем же способом. Настройки сохранятся. Разрешение «Универсальный доступ» должно сохраниться, но после обновления проверьте: если двойное Cmd+C перестало работать, включите DeepRrr там заново.

## Удаление

- **Программу**: закройте DeepRrr (значок в строке меню > Quit DeepRrr) и перенесите `~/Applications/DeepRrr.app` в Корзину.
- **Настройки** (отдельно, если хотите убрать всё): файл `~/Library/Preferences/dev.av.deepr.plist` (там же ключ Gemini, если вводили) и папка `~/Library/Application Support/DeepR`. И выключите DeepRrr в «Универсальном доступе».

## Установка с помощью ИИ-агента

Если у вас есть Claude Code, Codex или похожий агент, можно попросить его:

> Установи DeepRrr из ~/Downloads по инструкции https://github.com/vokhmin/deepr-releases/blob/main/INSTALL.ru.md, следуй разделу про ИИ-агента.

Если агент не может открыть ссылку, дайте ему текст этой инструкции.

**Что делает агент:** проверяет, что Mac на Apple Silicon с macOS 15+ и есть ли уже установленный DeepRrr; проверяет контрольную сумму установщика (`shasum -a 256 -c install-deepr.sh.sha256`, должно быть OK) и только потом запускает его с тем файлом, который вы назвали; сообщает вам результат.

**Где агент обязан остановиться и сказать вам:** не совпала контрольная сумма или установщик сообщил о любой проваленной проверке; DeepRrr не закрывается. Агент не должен обходить проверки, переподписывать приложение, снимать отметку о загрузке из интернета, менять настройки безопасности macOS или скачивать файлы откуда-то ещё, кроме названного вами источника.

**Что делаете только вы:** отвечаете на вопрос macOS об открытии приложения; включаете DeepRrr в «Универсальном доступе» (и при желании в «Записи экрана и системного звука»); скачиваете языки Apple; вводите свой ключ Gemini, если нужен (агент не должен его спрашивать и никуда записывать).

Агент не удаляет ваши настройки и данные при установке или обновлении и не удаляет DeepRrr, если вы об этом не просили.

**Предварительная сборка через агента.** Агент может выполнить шаги 1-4 и 7 раздела «Предварительная сборка»: скачать два файла только со страницы релизов, проверить контрольную сумму и выполнить блок из шага 4 без изменений (он должен закончиться `УСТАНОВЛЕНО И ПОДПИСЬ ВЕРНА`; при любой другой концовке агент останавливается и ничего не исправляет сам). Отпечаток сертификата сверяете вы с сообщением автора. Шаг 5 («Всё равно открыть») и разрешения делаете только вы: агент не снимает карантин (`xattr`), не меняет Gatekeeper (`spctl`) и не переподписывает приложение.
