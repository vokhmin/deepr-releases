# DeepR

DeepR - маленький переводчик для Mac в духе DeepL: выделяете текст, дважды нажимаете Cmd+C, и рядом появляется перевод; есть и окно с двумя панелями, оригинал и перевод. По умолчанию переводит встроенный переводчик Apple, без аккаунтов и подписок. Это личный проект, которым автор делится с друзьями и коллегами.

*DeepR is a small DeepL-style translator for macOS. English install guide: [INSTALL.md](INSTALL.md).*

> **Статус:** первой сборки ещё нет. Она появится на [странице релизов](https://github.com/vokhmin/deepr-releases/releases) после подписи и заверения у Apple (нотарификации) и проверки на чистом Mac.

## Требования

- Mac на Apple Silicon (M1 и новее), macOS 15 или новее.
- Инструменты разработчика не нужны.

## Установка

Пошагово: [INSTALL.ru.md](INSTALL.ru.md) (по-английски: [INSTALL.md](INSTALL.md)). Коротко: скачайте четыре файла одной версии со страницы релизов, проверьте контрольную сумму установщика и запустите его. Установщик сам проверяет, что приложение подписано автором (Apple Developer ID) и заверено Apple, и ничего не ставит, если проверка не прошла.

## Что лежит в каждом релизе

| Файл | Что это |
| --- | --- |
| `DeepR-<версия>.zip` | приложение |
| `DeepR-<версия>.zip.sha256` | контрольная сумма приложения |
| `install-deepr.sh` | установщик |
| `install-deepr.sh.sha256` | контрольная сумма установщика |
| `DeepR-<версия>-source.tar.gz` | исходный код этой версии (AGPL) |
| `release.txt` | из какого коммита и как собрано |

Автоматические архивы «Source code» на странице релиза содержат только эту документацию; исходный код приложения лежит в `DeepR-<версия>-source.tar.gz`.
