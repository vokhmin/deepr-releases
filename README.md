# DeepRrr

DeepRrr (раньше DeepR) - маленький переводчик для Mac в духе DeepL: выделяете текст, дважды нажимаете Cmd+C, и рядом появляется перевод; есть окно с двумя панелями (оригинал и перевод) и словарная статья по выделенному слову. По умолчанию переводит встроенный переводчик Apple, без аккаунтов и подписок. Это личный проект, которым автор делится с друзьями и коллегами.

*DeepRrr is a small DeepL-style translator for macOS. English install guide: [INSTALL.md](INSTALL.md).*

> **Статус:** сборок, заверенных Apple, пока нет. Вышла первая **предварительная сборка** `0.21.0` preview для пробной установки у друзей: она подписана сертификатом автора, но не проверена Apple, поэтому первый запуск нужно разрешить вручную. Скачивать на [странице релизов](https://github.com/vokhmin/deepr-releases/releases), ставить по разделу [«Предварительная сборка»](INSTALL.ru.md#предварительная-сборка-без-заверения-apple).

## Требования

- Mac на Apple Silicon (M1 и новее), macOS 15 или новее.
- Инструменты разработчика не нужны.

## Установка

Пошагово: [INSTALL.ru.md](INSTALL.ru.md) (по-английски: [INSTALL.md](INSTALL.md)). Коротко для предварительной сборки: скачайте архив и его контрольную сумму, сверьте сумму, распакуйте и выполните один блок команд из инструкции: он проверяет подпись автора и ставит приложение в `~/Applications/DeepRrr.app`. Затем один раз разрешите запуск в Системных настройках > Конфиденциальность и безопасность > «Всё равно открыть».

**Отпечаток сертификата автора:** `d7b862527611395df9bb15be986dfd655f32ea09`. Автор пришлёт его вам и отдельным сообщением; если они не совпадают, ничего не ставьте.
